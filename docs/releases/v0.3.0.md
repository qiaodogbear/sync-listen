# Sync Listen v0.3.0 Preview

一台 Android 手机就可以托管一起听歌的房间，朋友的手机或 Windows 客户端加入后下载同一份本地音频，再同步播放。不要求电脑在场，也不需要音乐账号。

本版面向互通、可信的 Wi-Fi / 手机热点网络。不是公网文件服务，也不保证专业音箱的声学同步。

## 下载

- `SyncListen-v0.3.0-android.apk`：Android 8.0+，正式独立签名，包名 `com.synclisten.app`。
- `SyncListen-v0.3.0-windows-x64.zip`：解压整个目录后运行 SyncListen.exe，内含 Java 21 运行时。
- `SyncListen-v0.3.0-third-party-sources.zip`：随附音频库和运行时对应源码，普通使用无需下载。
- `SHA256SUMS.txt`：下载后校验 SHA-256。

## 本版改进

- 设备身份和房间邀请分离，服务端验证角色与操作人，阻止成员冒充房主。
- Android 托管状态事务化，父表使用非删除式 Upsert，修复连续恢复丢失播放列表；异常中断后可恢复原房间并暂停继续。
- 修复列表重排冲突、暂停/seek/曲终重播、取消和重连、批量选择与下载校验问题。
- 重构 Windows 播放器生命周期并补齐自动下载、hash 校验和缓存就绪后同步。
- 完善创建/加入引导、邀请确认、角色刷新、服务器切换限制和诊断信息。
- 完成八块工程审查、架构图、使用指南与工程看板，完善签名、打包、许可证和 CI 配置。

## 使用与升级

所有设备连入同一 Wi-Fi/热点；房主创建房间，成员扫码或填写房主地址与房间码；添加本地音频，缓存就绪后播放。手机托管默认端口 38571。Windows 当前作为客户端加入手机或 Node 后端，不提供桌面托管入口。

**本版协议不兼容旧版无鉴权房间。** 请全部设备升级后重建房间。Debug 与正式 applicationId 不同；同包名但签名不同的旧测试包不能覆盖安装，先保留需要的数据再卸载旧包。
