# 使用指南

## 手机托管：无需电脑

1. 从 GitHub Release 安装 Android APK。让所有手机连接同一 Wi-Fi，或连接房主开启的热点。
2. 房主点「创建房间」，填昵称和房间名，确认网络互通并允许通知，创建后进入房间。
3. 点「邀请」展示二维码。成员可扫码，或点「加入房间」填写房主的 http://局域网IP:38571 与六位房间码。
4. 任一成员在房间点「添加」，从系统文件选择器选择本地音频。先等文件检查完成，再开始上传；不要把受 DRM 保护的流媒体缓存当作普通音频文件。
5. 等缓存就绪后由房主选歌。Host/Admin 可播放、暂停、拖动和切换；普通 Member 收听和上传。房主可长按成员头像调整角色。
6. 房主「结束房间」会断开所有人；成员「离开房间」只退出自己。不使用时应显式结束托管，减少耗电。

地址中的 127.0.0.1 / localhost 表示当前设备本身，不能发给另一台手机。房间码也不是全球地址，必须配合正确服务器地址。同一 Wi-Fi 不保证互通，酒店、校园及部分热点可能开启设备隔离。

## Windows 加入

解压整个 Windows 包后运行 SyncListen.exe，不要单独移动 exe。首次设置服务器为手机房主的局域网地址（端口 38571），填昵称与房间码加入。也可连接自己运行的 Node 后端（默认端口 3000）。当前桌面 UI 不提供独立托管模式。

建议用短 PCM WAV 先确认连接、上传与播放。桌面本轮对 WAV 做了验证，MP3 等格式仍需按实际文件验证。

## 没有互联网怎么办

首次下载/安装之后，同一 Wi-Fi 或热点内的手机托管不要求互联网。仍需要 Wi-Fi 局域网连接；BLE 与 NFC 仅用于邀请，不会传输音乐，也不能替代房间网络。

## 中断与恢复

- 短时网络断开：已缓存的歌曲可继续本地播放，恢复连接后重新接收房间状态；未缓存歌曲无法凭空播放。
- 房主被强制停止：重新打开 App，首页可出现恢复卡片；恢复原房间后先暂停，由房主决定何时继续。保存位置不保证是中断前最后一毫秒。
- 主动结束房间：不提供恢复。普通成员退出 App 后需要重新加入。
- 切换 Wi-Fi/IP：旧邀请可能失效，检查房主的新地址；版本 0.3.0 的凭据按地址 origin 隔离，必要时创建新房间。

## 常见疑问

**必须开电脑吗？** 不必须。手机创建房间时自身就是协调节点；电脑后端是可选方案。

**为什么成员有时候晚开始？** 需要先下载并校验文件，再准备解码器。当前还没有全体成员就绪门槛，建议先等缓存完成。

**能当多音箱系统吗？** 不能保证。软件播放进度接近，并不补偿蓝牙或声卡延迟。

**能通过公网邀请任意朋友吗？** 本预览版不提供安全的公网托管服务。不要直接把 HTTP 服务暴露在公网。

**允许朋友分享任何音乐吗？** 请只上传、使用和分发你有权处理的内容。软件不提供版权授权或 DRM 绕过。

需要排查时先查看房间诊断信息，再参照 [调试指南](debugging.md) 和 [已知限制](known-issues.md)。
