## Desktop Audio Libraries

Unmodified Maven artifacts from [soundlibs](https://github.com/pdudits/soundlibs):

- com.googlecode.soundlibs:jlayer:1.0.1.4
- com.googlecode.soundlibs:mp3spi:1.9.5.4
- com.googlecode.soundlibs:jorbis:0.0.17.4
- com.googlecode.soundlibs:tritonus-share:0.3.7.4

The [soundlibs 1.4 parent POM](https://repo.maven.apache.org/maven2/com/googlecode/soundlibs/soundlibs/1.4/soundlibs-1.4.pom) declares LGPL 2.1. The Windows distribution includes the original source JARs and POMs in third-party-sources, and the LGPL text in licenses. Original source headers take precedence for individual files. We have not modified these libraries.

The libraries remain separate JARs under app; recipients may replace compatible library JARs. This project imposes no restriction on reverse engineering for debugging modifications to LGPL components. The Sync Listen source and Gradle build are available in this repository to rebuild the application with replacements.

## Bundled Java Runtime

The Windows package contains Eclipse Temurin 21.0.11+10. Preserve runtime/legal and its license files. Adoptium identifies its binaries as GPLv2 with the Classpath Exception in its [official FAQ](https://adoptium.net/docs/faq).

The matching upstream source distribution is available with the [official jdk-21.0.11+10 release](https://github.com/adoptium/temurin21-binaries/releases/tag/jdk-21.0.11%2B10), asset OpenJDK21U-jdk-sources_21.0.11_10.tar.gz. We redistribute the unmodified runtime generated by the JDK's packaging tools, not a proprietary Java implementation.
